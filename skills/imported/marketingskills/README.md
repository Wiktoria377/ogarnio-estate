# Skills zaimportowane z `marketingskills-main` (Corey Haines, licencja MIT)

Pliki w tym katalogu to **zaadaptowane** (przetłumaczone, skrócone i dopasowane do marketingu
nieruchomości) fragmenty oryginalnych skills. Oryginały były pisane dla agentów AI pracujących
w terminalu (Claude Code, Cursor) i zawierają m.in. odwołania do plików `.agents/product-marketing.md`,
narzędzi CLI i integracji, które w tej aplikacji nie mają zastosowania — te części pominięto.

Każdy plik ma w frontmatter `source.path` (ścieżka w oryginalnym repozytorium) i `upstream_version`.
Pełny raport inwentaryzacji: `docs/SKILLS_AUDIT.md`.
